# Entre Capas - Colleen Hoover
Site desenvolvido para a disciplina de Desenvolvimento Web I.

## Sobre o projeto
O projeto apresenta um site dedicado às obras da escritora Colleen Hoover.
O site apresenta informações sobre a autora, algumas de suas obras e temas
presentes em suas histórias.
